# GitPulse — Roadmap

## MVP

Goal:

> Prove that GitHub activity can become a cool, listenable, reactive audio-visual experience.

Includes:

- single GitHub username;
- multiple usernames merged into one composite profile;
- public GitHub data fetch;
- demo dataset;
- generated Tone.js audio;
- React Three Fiber visualiser;
- Futuristic, Playful, and Epic moods;
- tempo, intensity, remix controls;
- static deployment;
- strong repo documentation.

---

## Version 0.2 — Better data and polish

- improve GitHub API resilience;
- add richer public events where available;
- improve normalised activity timeline;
- add shareable URL state;
- add screenshots/GIFs;
- improve mobile layout;
- add accessibility pass;
- add reduced motion option.

---

## Version 0.3 — Contribution calendar

- add GitHub GraphQL support;
- add GitHub OAuth login through a Cloudflare Worker broker;
- keep optional manual token support as an advanced development fallback;
- proper contribution calendar mapping;
- richer PR/issue/review signals;
- better streak detection;
- more accurate multi-account activity grid.

---

## Version 0.4 — Creative controls

- expose mapping controls;
- choose commit sound;
- choose repo layer type;
- choose scale/key;
- add swing/groove;
- add reverb/delay controls;
- add more visual tuning.

---

## Version 0.5 — Account layering

- account panning;

- personal vs work account breakdown.
